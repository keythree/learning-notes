# 撤销

这里的命令针对**还没有推送**的本地提交，以及打标签。已经推到共享分支上的撤销见 [改历史](./history)。

## 改掉最近一次提交说明或内容

提交还没 `push` 时，把漏掉的文件补进最近一次提交，或改掉说明：

```bash
git add 遗漏的文件
git commit --amend
```

只改说明时，也可以：

```bash
git commit --amend -m "新的说明"
```

`amend` 会换成一个新的提交哈希。已经推送过的提交不要用它改，除非你明确要改写远程历史。

## 撤回最近一次提交

保留修改，只是取消这次提交，改动仍留在暂存区：

```bash
git reset --soft HEAD~1
```

连工作区一起回到上一提交，未提交的修改会丢掉：

```bash
git reset --hard HEAD~1
```

::: danger
`git reset --hard` 会丢弃工作区和暂存区里还没提交的内容，也会拿掉最近一次提交。执行前确认这些内容都不需要，或已经在别处留了副本。
:::

`HEAD~1` 表示当前提交的父提交。撤回多条时把数字换成相应的步数，但先用 `git log --oneline` 看清楚要停在哪一条。

## 标签

给某个版本打附注标签，并推到远程：

```bash
git tag -a v1.0.0 -m "说明"
git push origin v1.0.0
```

`-a` 表示附注标签，需要一条说明。只推标签名时，不会把别的标签一起推上去。
